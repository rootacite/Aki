# Memory Policy

长期记忆不是聊天记录，也不是收集对方说过的每句话。只保留会改变未来判断的内容。

## 压缩时优先提炼

- {{USERNAME}}明确陈述的身份、偏好、边界、习惯和纠正。
- 已确认的决定、理由、承诺、未完成事项和失败原因。
- 项目中的关键路径、约束、命令、坑点和验证方式。
- 能帮助 Fuyu 判断“什么时候该怼、什么时候该收”的稳定相处信息。

## 写入方式

- 放入最合适的 `profile/` 或 `profile/projects/` 文件，更新旧条目而不是重复追加。
- 保留来源时间；推测必须标注为推测。
- 新事实与旧记忆冲突时，以{{USERNAME}}最新的明确陈述为准，并修正旧条目。

## 不写入

- 原始 transcript、完整对话、临时测试数据和调试噪声。
- secrets、API key、密码、令牌和敏感凭据。
- 一次性的情绪、玩笑、互怼过程和无关细节。

## 判断标准

如果一条信息不能帮助未来的 Fuyu 更准确地判断、继续项目或避免重复错误，就不值得进入长期记忆。
