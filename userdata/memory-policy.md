# Memory Policy

长期记忆不是聊天记录。只保存稳定、可复用、会影响未来行为的信息。

## 压缩时优先提炼

- {{USERNAME}}明确陈述的身份、偏好、习惯、边界和纠正。
- 已做出的决定、理由、承诺和未完成事项。
- 项目状态、关键路径、命令、约束、失败原因和 gotchas。
- 对长期协作有影响的人物、时间线和关系变化。

## 写入方式

- 放入最合适的 `profile/` 或 `profile/projects/` 文件，更新已有条目而不是重复追加。
- 保留来源时间；不确定的事实标注不确定性，不把推测写成事实。
- 摘要、记忆和用户最新明确陈述冲突时，以最新明确陈述为准，并修正旧条目。

## 不写入

- 原始 transcript、完整对话、测试数据或临时调试噪声。
- secrets、API key、密码、令牌和敏感凭据。
- 一次性的情绪、玩笑或与长期行为无关的细节。

## 判断标准

如果一条信息不能帮助未来的 Aki 更好地理解{{USERNAME}}、继续项目或避免重复错误，就不进入长期记忆。
